# بيت الهمس — Whispering House

لعبة رعب (اللعب الفردي من غير موت — خضّات بس. واللعب الأونلاين فيه موت). بتشتغل على **ويندوز (EXE)** و**أندرويد (APK)**، وبنفس الكود (`main.py`).

## الملفات
| الملف | وظيفته |
|---|---|
| `main.py` | اللعبة كلها (كمبيوتر + موبايل) |
| `netplay.py` | اللعب الأونلاين على الشبكة المحلية (سيرفر الغرفة + الاتصال + البحث) |
| `assets/` | اللوجو والأيقونات والخط |
| `build_exe.bat` | بيطلّع ملف EXE بضغطة واحدة |
| `buildozer.spec` + `p4a-recipes/` + `src/` | إعداد بناء الـ APK |
| `.github/workflows/build.yml` | بيبني EXE و APK أوتوماتيك على سيرفرات GitHub المجانية |

---

## 1) ملف EXE (ويندوز)

1. نزّل **Python 3.11** من python.org — وقت التثبيت علّم على **Add Python to PATH**.
2. فكّ ضغط المشروع، واضغط مرتين على **`build_exe.bat`**.
3. استنى دقيقتين تلاتة. الملف هيطلع في: **`dist\BaytAlHams.exe`** (أيقونته اللوجو).

الحفظ (`savegame.json`) بيتعمل جنب الـ EXE. تقدر تنسخ الـ EXE لأي مكان.

> نطق الاسم على ويندوز: بيشتغل بصوت ويندوز العربي. لو مش شغّال نزّل صوت عربي من إعدادات Speech في ويندوز.

---

## 2) ملف APK (أندرويد) — أسهل طريقة: GitHub (من غير ما تنزّل حاجة)

الـ APK بيتبني على Linux، فبنستخدم سيرفرات GitHub المجانية:

1. اعمل حساب على github.com (مجاني) → **New repository** → سمّيه أي اسم (خليه Private لو عايز).
2. ارفع **كل محتوى فولدر المشروع** (Upload files). **مهم:** لازم فولدر `.github` يترفع كمان.
3. اضغط تاب **Actions** → اختار **Build EXE and APK** → **Run workflow**.
4. استنى. الـ APK بياخد من **25 لـ 40 دقيقة** أول مرة. الـ EXE بياخد 3 دقايق.
5. افتح الـ run اللي خلص ونزّل من تحت (**Artifacts**):
   - `BaytAlHams-APK` ← جواه ملف `.apk`
   - `BaytAlHams-EXE` ← جواه `BaytAlHams.exe`
6. فكّ الضغط، ابعت الـ APK لموبايلك، وسمح بـ **Install unknown apps** وثبّته.

### بديل: بناء الـ APK على جهازك (Linux أو WSL2 على ويندوز)
```bash
sudo apt update && sudo apt install -y autoconf automake build-essential ccache cmake gettext git \
  libffi-dev libltdl-dev libncurses5-dev libncursesw5-dev libssl-dev libtinfo5 libtool \
  openjdk-17-jdk patch pkg-config unzip zip zlib1g-dev
pip install --upgrade buildozer "Cython<0.30" virtualenv appdirs packaging colorama jinja2 toml build
cd مسار_المشروع
buildozer -v android debug
```
الناتج في فولدر `bin/`.

## تجربة شكل الموبايل على الكمبيوتر
```
python main.py --touch
```
هتفتح نافذة بشكل الموبايل (جويستيك + أزرار + كيبورد على الشاشة) وتتحكم فيها بالماوس.

## ملاحظات مهمة
- **أول تشغيل على الموبايل** بياخد حوالي 10 ثواني (بيجهّز الأصوات)، وبعد كده بيفتح بسرعة.
- **نطق الاسم على أندرويد** بيستخدم محرّك Google TTS في الموبايل. لو مفيش صوت عربي متنزّل (Settings ← Text-to-speech) الوحش هيهمس بس.
- لو فشل بناء الـ APK: ابعتلي آخر 40–50 سطر من الـ log. ولو الخطأ عن `pyjnius` شيله من `requirements` في `buildozer.spec` (اللعبة هتشتغل من غير نطق الاسم).
- عشان تغيّر اسم التطبيق على الموبايل: `title` في `buildozer.spec`. وتغيّر الأيقونة: استبدل الصور في `assets/`.
- الخط: IBM Plex Sans Arabic (رخصة OFL مفتوحة).

## اللعب الأونلاين (LAN)

من القايمة الرئيسية اختار **اللعب أونلاين**. لحد **8 لاعبين** على نفس الواي فاي / الشبكة.

- **إنشاء غرفة:** بتاخد رقم من 6 أرقام (مش متكرر على الشبكة). ابعته لأصحابك واضغط **ابدأ اللعبة** لما يدخلوا.
- **الانضمام لغرفة:** اختار الغرفة من القايمة (بتظهر لوحدها)، أو اكتب رقمها واضغط **انضم**. لو الشبكة بتمنع البحث التلقائي اكتب **IP جهاز المضيف** (بيظهر في اللوبي).
- كل لاعب بيدوّر على مفاتيحه وبطارياته بنفسه، والبيت واحد عند الكل، وبتشوفوا بعض وكشافات بعض.
- **الموت:** اللاعب بيموت لو شريط الخوف اتملى، أو وحش لمسه. اللي مات بيتفرّج على زمايله (الأسهم أو E للتبديل).
- **الشقة الجاية:** لما مفيش حد حي، ولو فيه حد هرب، الكل بيروح للشقة الجاية واللي ماتوا بيرجعوا للحياة. ولو الكل مات الشقة بتتعاد.
- مفيش حفظ في الأونلاين، والمضيف لو خرج الغرفة بتتقفل.
- على الموبايل لازم **الواي فاي** (مش بيانات) وإذن الشبكة موجود في `buildozer.spec`. على ويندوز اسمح للعبة في الـ Firewall لما يسألك.
- الأرقام المستخدمة: TCP `47778` و UDP `47777` (للبحث).
- للتعديل: `FEAR_DEATH` في أول `main.py` (حد الخوف)، و`RESTART_DELAY` في `netplay.py`.
